Flujo General del Usuario
1. Ingreso desde la Landing Page

La persona llega a la landing page, interactúa con la calculadora y solicita un préstamo.

Luego es redirigida a la plataforma.

2. Registro / Inicio de Sesión
Si no está logueado:

Se le muestra la pantalla de registro.

Debe ingresar los siguientes datos:

Correo electrónico
Número de celular
DNI
Contraseña

También se le brinda la opción de registrarse con Google, si no desea ingresar correo manualmente.

Después del registro, se valida el número de celular mediante OTP.

Una vez validado, ya tiene una cuenta activa.

Si ya tiene cuenta:

Puede iniciar sesión directamente.

3. Inicio del Funnel desde la Calculadora

Una vez que inicia sesión, como viene desde la calculadora, se le redirige automáticamente al flujo de formularios.

4. Validación Inicial de DNI (solo cuentas nuevas)

Antes de ingresar a todos los formularios, como es una cuenta nueva, se deben validar los datos básicos del DNI para confirmar que la persona es quien dice ser.

Se le solicitará:

Nombres
Apellidos
Código de verificación del DNI

Si los datos coinciden, continúa al flujo.

5. Formularios y Resumen

El usuario completa los formularios hasta llegar al resumen final.

En el resumen debe mostrarse el botón:

Enviar a revisión

Al hacer clic, se genera una solicitud.

6. Si la Solicitud Sale Preaprobada
Caso 1: Usuario nuevo (sin validación biométrica previa)

Como nunca validó identidad completa, se le solicitará:

Foto frontal del DNI
Foto reverso del DNI (si aplica)
Selfie

Luego se le muestra el contrato para firma.

Después de eso, el sistema valida todo, aprueba el préstamo y recién se desembolsa.

Caso 2: Usuario antiguo (ya validó identidad antes)

Si el usuario ya había validado anteriormente:

DNI
Fotos del DNI
Selfie

Entonces ya no se le vuelve a pedir esa información.

Solo se le muestra el contrato para aprobación, y luego se desembolsa el préstamo.
